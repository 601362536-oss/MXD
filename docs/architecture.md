# 架构说明

## 设计原则

- 前端只负责页面、交互、表单、图表展示。
- 后端负责接口、权限、数据关系、行情计算。
- 管理后台和用户前台读取同一套数据库，不再各自写死。
- 物品、装备、怪物、掉落、帖子、攻略、行情都必须模块化。

## 模块边界

### 用户端

- 首页：推荐位、汇率卡片、热门内容
- 图鉴：怪物资料、掉落关联
- 物品：物品库、装备库、分类筛选
- 行情：金币汇率、区服、分时、K线
- 资讯：论坛式帖子
- 开荒：攻略卡片流
- 个人中心：资料、帖子、攻略

### 管理端

- 首页配置
- 行情后台
- 物品与装备管理
- 怪物与掉落管理
- 内容与评论管理
- 用户与权限管理
- 系统设置
